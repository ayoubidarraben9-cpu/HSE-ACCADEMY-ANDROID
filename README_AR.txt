HSE ACADEMY - مشروع Android لإنتاج APK

هذا المشروع يغلّف نسخة HSE ACADEMY الحالية داخل تطبيق Android يعمل دون اتصال بالإنترنت.

إنتاج APK مجاناً عبر GitHub:
1) أنشئ حساباً في GitHub.
2) أنشئ مستودعاً جديداً وارفع جميع محتويات هذا المجلد إليه.
3) افتح تبويب Actions في المستودع.
4) اختر Build HSE ACADEMY APK ثم Run workflow.
5) بعد انتهاء البناء بنجاح، افتح نتيجة التشغيل ونزّل Artifact باسم HSE-ACADEMY-debug-apk.
6) فك ضغط الملف الذي تم تنزيله وستجد app-debug.apk. انقله إلى هاتف Android وثبّته بعد السماح بالتثبيت من هذا المصدر.

للبناء محلياً: افتح هذا المجلد في Android Studio، انتظر مزامنة Gradle، ثم اختر Build > Build Bundle(s) / APK(s) > Build APK(s).

ملاحظات:
- هذه نسخة Debug للتجربة والتثبيت الشخصي، وليست APK موقّعة للنشر على Google Play.
- لا توجد حالياً حسابات مستخدمين أو مزامنة سحابية؛ التقدم محفوظ محلياً على الجهاز.
- المحتوى تعليمي ولا يعوّض إجراءات الموقع أو التكوين المهني المعتمد.
